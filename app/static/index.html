AI Research Assistant

A FastAPI service that answers questions from an indexed document set. Passages are chunked, vectorized with TF-IDF, and retrieved by cosine similarity, then handed to a language model so every answer is grounded in a cited source. With no model configured, you get the cited passages directly.

    Architecture

    Documents and queries pass through the same vectorizer so a question can be compared directly against every stored passage. Hover a step below to trace it above.

    fig. 1Ingest

    Accepts a source file, strips it down to plain text, and normalizes encoding before anything is split.

    fig. 2Chunk

    Splits normalized text into overlapping passages on paragraph and sentence boundaries where possible, so a passage rarely opens or closes mid-thought.

    fig. 3Vectorize

    One TF-IDF vectorizer, fit across every stored passage, turns both passages and incoming queries into vectors in the same space.

    fig. 4Retrieve

    A cosine-similarity search over the vector index returns the closest passages, filtered by a minimum relevance score.

    fig. 5Synthesize

    A language model is prompted to answer using only the retrieved passages, and to say so when the answer isn't among them, citing the passage it drew from.

    §4

    Design notes

    01

    TF-IDF over a neural embedding model

    No GPU, no model download, no embedding API key. Ingestion works the moment the service starts. The vector-store interface doesn't care how a vector was produced, so a dense embedding model is a one-file swap, not a redesign.

    02

    Retrieval and generation share nothing but the index

    The retriever has no knowledge of which model will read its output. Either the vectorizer or the language model can be swapped independently.

    03

    Answers are grounded, not paraphrased from memory

    The system prompt constrains the model to the retrieved passages and instructs it to say when an answer isn't among them, rather than fall back on what it already knows.

    04

    The evidence is never hidden behind the answer

    Every response includes the retrieved passages, their document, and their relevance score, whether or not a language model was available to summarize them.
